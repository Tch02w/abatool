# 后处理功能说明与修改导航

关联：F014–F022；任务 TASK-001。当前是可运行核心加未完成验收，不是最终发布声明。精确文件路径集中在 [功能索引](FUNCTION_INDEX.md)，证据与缺口见 [验收记录](../06-testing/VALIDATION.md)。

## 1. 用户模型与优先级

用户的两类基础：钢筋根键基础（工字钢根键）；钢管护壁根键基础（主体素混凝土、圆钢管根键），以及对应灌注桩对照。不能只凭 GJA/GJB 名称、截面外形或集合名推断单元类型/配筋；应读取实际 ODB/配置。

当前用户模型没有梁单元。优先完成实体根键、混凝土、钢管的截面应力积分和实际钢筋单元轴力。B31 人工 ODB 仅是通用读取器测试，不是用户模型，不是当前工程验收依据。

## 2. 两条使用路径

### 原有基础后处理

ODB 后处理 → 选择根目录 → 发现 ODB → 检查兼容性 → 读取结构与默认参数 → 编辑提取参数/分组/图例 → 运行后处理 → 打开结果浏览。

**对比组的云图色标（F020）：** 多选要比较的 ODB，在“选择与对比组”中填写同一组名并点“应用分组”，保持这些成员选中，点“运行后处理”。运行计划只含本次选中的行；未分组 ODB 各自单独处理。默认按组、按变量汇总，静态云图取各成员选定帧的公共范围，`_LAST` 图画所选帧中的最后一帧；GIF 取各成员所选分析步的完整时程范围。混凝土拉/压损伤各自从 0 起算；“图例范围”可按变量手动覆盖该组静态图和动画的范围。共享数值结果不按色标缩放；组色标用于后续绘图，不适用于只导出 CSV 的通用对象内力入口。

分组计划保存在结果根目录的 `_批次记录/<组批次>/comparison_group_legends.json`，成员输出的 `metadata.json` 分别记录 `legend_ranges` 和 `animation_legend_ranges`。预扫描跳过帧中不存在的场，渲染器未将缺少组范围一律当作错误：普通场静态图及无范围的动画可退回 Abaqus 自动范围，缺范围的静态损伤图使用 0 到 1e-12。因此未核对范围的图不能直接认作严格同标尺。核查证据见 [TASK-001](../08-handoff/ACTIVE_TASKS/TASK-001-postprocessing.md)。

这条路径继续复用 WinUI 前的提取、钢筋贡献处理、图表、云图和动画逻辑。无纵筋模型显式使用 `reinforcement_mode=none`；不能为了通过检查伪造钢筋集合。结构预检应先检查整批输入，避免前组已经运行后才发现后组配置无效。

### 通用对象提取

读取结构后单选一个 ODB → “浏览实例、集合与可用输出…” → 搜索/选择实例或单元集 → 指定分析步及帧 → 选择方法 → “提取所选对象”。旧缓存缺少目录时勾选“本次强制重扫”，重新读取结构。

目录支持装配/实例节点集与单元集，但**当前内力提取只接受非空实例或单元集**，节点集只供浏览。界面按目录中实际单元类型确定可用方法：实体、桁架和梁分别匹配 worker 支持范围；节点集、空集、壳、未知类型或跨族混合集合不能提交。类型计数缺失/不完整时要求强制重扫，不再默认归入梁。整帧字段列表不是所选集合必有数据的保证。UI 当前可选单帧或所选分析步全部帧；未实现任意帧范围编辑或通用方案长期保存。

## 3. 方法、口径与边界

| 方法键 | 适用对象 | 输出与约定 | 拒绝/限制 |
|---|---|---|---|
| `solid_section` | 支持的 C3D 实体单元集或整个实例 | CAE 自由体切面应力积分；全局 Fx/Fy/Fz、Mx/My/Mz；另给法向轴力、扭矩及弯矩大小 | 参考几何/未变形切面；不自动叠加钢筋；不能套用到壳、梁、混合不支持单元 |
| `truss_reference_area` | 支持的桁架/钢筋单元 | S11 × 参考截面积；按实例、单元、积分点输出 | 必须确认有限变形限制；不等同当前截面积轴力；ODB 无面积时必须显式提供，不猜直径 |
| `beam_sections` | 支持的梁/PIPE 单元，通用扩展 | ODB 已保存的 SF/SM 局部截面分量 | 用户现有模型不使用此法；不把不同积分点/沿构件的力直接累加 |

实体参数：基准点、非零法向、沿单位法向的截面偏移列表、力矩参考点。参考点为空时取截面形心；固定参考点用于明确比较弯矩。单位全部沿用模型，不自动假定 mm/N。

关键实现约束：

- 真实 ODB 中父字段与 `getSubset` 后分量标签数量可能不同，必须按子集标签读取数据。
- 缺帧、缺字段、不完整单元覆盖、复数、非有限数值不能解释为零。
- CAE ViewCut 的初始位置不一定为提供的原点，必须显式设置 `position=0`。
- CAE 报告 CutX/Y/Z 是力矩参考点，不能当作切面位置；CSV 分开保存两者。
- 改动截面算法时，需要已知应力样例 + 真实模型对照；生成了文件不是正确性证明。

## 4. API 与数据格式定位

新请求：`POST /api/v1/odb-region-extractions`；任务使用已有后处理操作查询/取消通道。协议 schemaVersion 为 1。精确必填字段和未知字段策略以 `modules/control_plane/region_extraction.py` 的 `RegionExtractionRequest.from_payload` 及 C# `OdbRegionExtractionRequest` 为准。

请求的主要内容：clientRequestId、根目录、ODB 路径、对象作用域/类型/实例/名称、方法、显式 step/index 帧列表；面积覆盖与确认字段必须携带，非适用方法使用相应空值/false；实体增加 section 定义。Abaqus 命令由后台配置传给解析器，不是客户端任意 shell 命令。不能只传集合显示名称，以免装配与实例同名集合混淆。

通用输出目录：所选根目录 / `AbaqusODBPostProcessor_Results/通用对象提取` / 唯一批次 / ODB与对象名。文件：

- `request.json`：该批参数，可追溯。
- `region_values.csv`：UTF-8 BOM 长表，保留 step/frame/frame_value、instance/element、积分点/截面点、method/component/value、面积来源与 convention。
- 实体增加 cut_index、plane_x/y/z、normal_x/y/z、moment_reference_x/y/z；cut_index 不能再复用 section_point。
- `manifest.json`：成功回执，记录源、请求、行数、CSV 和单位口径。aggregation 对实体使用 `section_stress_integration`，对梁/桁架逐点输出使用 `none_per_element_per_output_location`。旧批次回执不重写，以 request.method 及 convention 复核其口径。
- `raw_sections`：实际 CAE 报告，仅实体方法。
- 失败时保留 `_postprocess_incomplete.json`、`failure.json`、可能的 `region_values.pending.csv`；结果浏览不能把这些目录发布为完整结果。

Abaqus 批处理即使脚本报错也可能退出 0，业务层必须核验成功回执与文件，不能仅看退出码。

### 来源核验与失败结果隔离（2026-10-28 恢复修复）

后台在接受请求时自动记录源 ODB 的大小、纳秒修改时间及头/中/尾各 64 KiB 的 SHA256 采样摘要，写入内部 request/manifest 的 `sourceIdentity`；客户端不能自行提供该字段。在启动前、worker 打开前、成功关闭 ODB 后、宿主验收和最终发布时复核。采样用于检测通常的修改或替换，不等同完整文件哈希校验；真实样本验收另做全文件 SHA256 前后对照。

worker 必须先成功关闭 ODB 并核对源文件，才写成功回执。宿主还核对请求、来源、行数及失败/未完成标记。批次级 `_postprocess_incomplete.json` 直到操作管理器锁内确认未取消才解除；因此源变化、关闭失败、无效回执、worker 完成后收到取消，都不会进入正式结果列表或索引。失败目录保留供定位，不覆盖已有成功批次。直接运行 worker 的人工校核入口仍在 worker 全部验证后正常发布。

当前跨控制面 Python 与 Abaqus Python 只比较上述稳定字段；文件编号、设备号和 ctime 仅在一次采样内检测变化，避免 Windows 不同 Python 版本的属性语义差异。

### 取消、失联恢复与结果查看

结构读取、基础批处理及通用对象提取在网络失败/等待超时时显示“状态待确认”，保留当前会话的请求编号及已收到的操作编号，暂停新提交。点击“查询原操作状态”每次最多等待 15 秒，只查询原操作，不重发提取请求；收到明确的 succeeded/failed/cancelled 终态后才解除锁定。正在取消时禁用重复停止，仅后台返回 cancelled 才显示已取消。请求信息目前在会话内保存；若后台重启丢失操作记录，仍保持待确认，不假定取消成功。

结果浏览在目录刷新并恢复选中范围后显式加载记录；索引成功时先解除索引忙状态，再刷新目录和记录。失败/取消不自动加载新索引。刷新失败清空旧目录、记录和预览；旧目录请求、旧记录响应或旧索引进度不能回填到新的选择。这些流程已有独立异步行为检查，原生完整点击仍单列验收。

### WinUI 结果列表与表格预览（F021）

在「结果浏览」中选择批次的时间目录、ODB 或公共数据版本，再按分类、数据用途或关键词筛选。超过 500 条匹配记录时，列表底部显示当前范围和「上一页」「下一页」。翻页沿用已经提交的筛选条件。提交新搜索或切换目录会回到第一页。选中文件和导出只作用于当前页。翻页读取失败时可在原页重试，索引失效时页面提示重新建索引。

选择 CSV 或 XLSX 文件后，预览区按单元格显示。CSV 第一行作为表头，Excel 使用首个工作表的 A、B、C 等列标，保留工作表内部的空行和空列。超过八列时可点「下一组列」或「上一组列」。单元格可选中文字；「复制预览」复制预览范围内的全部列，包含当前屏幕未显示的列。

不超过 1 MiB、1–20 MiB 和大于 20 MiB 的文件默认分别预览 50、25、12 行。存在后续行时显示「预览前 … 行」。需要完整数据时使用「打开文件」。切换文件会清除旧预览，损坏的工作簿显示读取错误。
