# 候选版本变更

本页记录用户可见变化，不表示已发布正式版本或完成全部迁移验收。

## 2026-11-18 · 输入草稿检查点与关机/注销入口

- 已登记的输入每两秒检查保存，未变化时不重复写盘；磁盘写入在后台串行执行，失败独立提示，原损坏文件保留。
- 系统确认结束时限时保存登记输入，不弹出普通关闭选择，不额外发送停止任务请求；取消注销后正常继续。
- 仅源码和独立检查通过，尚未进入完整候选，原生恢复未验收；后处理详细工作区、结果图和未确认弹窗的崩溃草稿恢复仍待补齐。

## 2026-11-18 · 按用户安装、升级和卸载候选

- 新增安装器构建与开始菜单入口，默认不要求管理员权限；应用负载逐文件校验。
- 不同版本使用独立目录，升级保留旧版本；检测到目标中的工作台或后台仍在运行则拒绝，不自动终止任务。
- 卸载仅移除登记的程序文件和入口，保留非程序文件与既有配置/队列目录。签名、无开发环境目标机和原生向导仍待验收。

## 2026-11-18 · 独立队列的视图与结果计划

- 指定独立队列文件的后台，其资源统计、重启动链和完整结果计划现与队列页使用同一来源；执行批量合并前也从同一队列复核，避免读到默认队列的其他记录。

## 2026-11-18 · 多作业队列响应与数据检查失败提醒

- 减少调度时重复读取模型文件信息：无历史时跳过查询，同轮共用文件元信息，下一轮重新检查变化。修复受测261行队列中运行状态读取超过5秒的问题；不保证任意工程/网络环境的响应上限。
- 数据检查失败也生成结束提醒，重启补查与已读去重保持一致。

## 2026-11-18 · 扫描期间的队列响应

- 外部扫描和日志诊断期间可读取最近保存的队列状态，不再等待整轮扫描；多目录共用进程查询。
- 扫描按钮显示进行中并防止重复触发。扫描期间被编辑、删除或重新执行的记录不被旧结果覆盖，跳过数量会在完成提示中显示。
- 扫描失败保留原队列，关闭后台后不合并迟到结果。原生业务页与工程负载的最终验收仍待完成。

## 2026-11-18 · 归档结束提醒补发

- 归档结束后后台意外退出，重启可补发已保存的归档提醒；清除已完成队列也保留提醒，已读不会重复变成未读。
- 提醒标题标明「本机归档」，「查看作业」定位原求解执行；同名的新执行不会冒充旧结果。
- 仍在归档的操作不误报中断，损坏回执保留并明确提示。源码及新完整包真实进程/正式客户端检查通过，原生点击仍待验收。

## 2026-11-18 · 本机归档候选

- 未勾选「归档后清理」时保留计算目录原文件；归档改为先复制、校验、完整发布。
- 归档失败或取消不再混淆求解结果；队列、作业概览和提醒展示独立归档结果。
- 部分归档不作为 Restart 前置或默认结果目录，新的执行不沿用旧归档字段。
- 新增作业概览「恢复归档」：后台中断后核对原执行记录、复用完整副本、继续复制或清理，不重新求解；期间可取消并阻止重复请求、编辑和目录冲突。损坏记录明确报告。
- 独立归档恢复已通过源码与新冻结包真实进程/正式客户端检查；确认完成后停止旧目录的恢复扫描，保留用户显式监测。跨卷负载和原生操作仍待验收。范围见 [归档说明](../03-features/LOCAL_ARCHIVE.md)，具体包及测试见 [当前状态](../08-handoff/CURRENT_STATUS.md)。
