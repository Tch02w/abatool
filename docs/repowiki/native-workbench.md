# 原生 WinUI 3 工作台

## 壳层

`MainWindow.xaml` 提供紧凑自定义标题栏、四组菜单、顶部导航、页面感知的左侧浏览器和底部实时状态栏。每个功能页拥有自己的上下文、日志和操作区，不再叠加静态属性栏或占位 TabView。

标题栏保留 Windows 原生最小化、最大化和关闭按钮；左侧胶囊标题随当前页面更新。状态栏显示短消息、本机资源、队列、远端连接、Abaqus 探测和控制面状态。

## 通用浏览器

左侧浏览器随当前页面切换信息结构：新建作业显示工作目录中的 INP、ODB、用户子程序和输出文件；作业队列同时显示目录候选、候选作业和正式队列；作业概览按运行、等待、异常和完成状态分组。单击节点联动页面选择，双击执行加载或导航。搜索、展开和选择按页面保留，后台刷新按稳定 ID 更新节点，不清空整棵树。

`WorkbenchExplorerHost` 提供统一视觉与交互，`IWorkbenchExplorerAdapter` 隔离各页面领域规则，`IWorkbenchExplorerPage` 是页面与壳层之间的接缝。八个业务页面均提供专用结构；兼容项目视图只在没有页面上下文时回退使用。

## 八个页面

1. 新建作业：本地或远程草稿、资源参数、路径选择、校验、命令预览和提交。
2. 作业队列：候选扫描、正式队列、排序、暂停、恢复、终止、并行上限和结果冲突策略。
3. 作业概览：运行状态、耗时、工作目录、日志与 STA/MSG/DAT 文件操作。
4. 计算资源：本机资源、服务器配置、SSH 指纹确认、刷新、文件上传下载和远程作业。
5. 重启动链：节点式计算图谱、分支、oldjob 拓扑、循环/缺失/路径校验、依赖编辑、队列定位和完整结果入口。
6. ODB 合并：与计算图分离的完整结果计划、手工单次合并、异步执行、进度、取消、失败清理和结果打开。
7. ODB 后处理：扫描、兼容性、分组、逐 ODB 参数、图例范围和批处理。
8. 结果浏览：索引构建、筛选、文本/表格/图片预览、打开、定位、复制和导出。

## 关键文件

- `MainWindow.xaml(.cs)`：导航、菜单、状态与统一关闭。
- `Controls/WorkbenchExplorerHost.xaml(.cs)`：浏览器外壳、筛选和状态恢复。
- `Explorer/*.cs`：稳定节点模型、页面接口与适配器。
- `Pages/*.xaml(.cs)`：页面视图和交互。
- `Services/ControlPlaneHost.cs`：控制面生命周期和 HTTP 调用。
- `Services/*Contracts.cs`：版本化 DTO。
