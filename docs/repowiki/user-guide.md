# Abaqus Tools 使用手册

更新于 2026-11-18。适用于当前 WinUI 3 源码版本。各项实际验证范围见 [验收记录](../06-testing/VALIDATION.md)，整体迁移状态见 [当前状态](../08-handoff/CURRENT_STATUS.md)。

## 启动和环境

当前提供源码启动方式和 Windows x64 自包含目录候选。源码方式需要 .NET 10 SDK、Python 3.14 和项目虚拟环境；目录候选携带控制面与界面运行库，须完整保留目录。ODB 读取、出图和合并仍需本机 Abaqus。安装依赖、构建和启动命令见 [README](../../README.md)，目录包限制见 [发布说明](../05-development/RELEASE.md)。

首次打开后，查看底部的 Abaqus 探测和控制面状态。若提示控制面不可用，检查项目根目录是否有 `.venv/Scripts/python.exe`。自定义解释器使用 `ABAQUS_TOOLS_PYTHON` 环境变量，自定义项目根目录使用 `ABAQUS_TOOLS_ROOT`。Abaqus 命令可填写安装目录下的 `abaqus.bat` 完整路径。启动失败的定位步骤见 [开发与发布](development.md)。

顶部导航固定包含新建作业、作业队列、作业概览、计算资源、重启动链、ODB 合并、ODB 后处理、结果浏览。左侧浏览器随页面显示对应文件或对象。数字输入的右侧下箭头减小、上箭头增加，数值居中。将鼠标移到参数旁的问号查看说明，移入提示区后可继续阅读，离开后自动关闭。

## 新建作业

1. 点击「选择 INP…」并填写作业名称。需要用户子程序时点击「选择 FOR…」。重启动作业需指定旧作业文件。
2. 选择本机计算、上传至已连接服务器或使用服务器现有文件。远端模式先在「计算资源」完成连接。
3. 填写 CPU、内存及其单位，并按模型需要选择精度和作业选项。CPU=0 采用 Abaqus 默认设置。正式队列入队时需要明确可调度的 Core 数。Abaqus ≤2021 的本机上限按逻辑线程计算，较新版本按物理核心计算。
4. 使用 SSD 计算时启用对应选项，填写计算目录和归档目录。核对预览中的实际工作目录、命令和 oldjob 参数。
5. 执行页面上的校验及提交操作。校验报错时先修正对应字段，随后重新预览。到「作业队列」核对条目，去「作业概览」查看运行过程。

本地和远程提交使用各自的路径格式。服务器现有文件模式中的路径以服务器文件系统为准。相同结果文件的处理方式应在运行前确定。

## 作业队列

候选区用于收集准备计算的 INP，正式队列用于调度。选择工作目录后可加入当前 INP、添加其他 INP 或扫描文件夹。扫描选项控制是否包括子文件夹、是否跳过 Restart 文件和已有结果的作业。勾选候选并点击「确认入队」，检查正式队列中的 Core、内存、优先级和重启动依赖。

设置「并行上限」后点击「开始队列」。暂停调度用于暂停后续派发，恢复调度继续派发。终止操作作用于正在运行的作业，应先核对当前选择和弹窗列出的影响。上下移动或重新排队会改变后续调度顺序，依赖检查仍需通过。

外部启动的作业可通过正式队列上方「工作目录 → 扫描」纳管。扫描后核对名称、路径与状态。结果冲突可选择备份旧结果等策略，具体动作以执行前预览为准。

## 作业概览和日志

选中一个作业后查看状态、进度、耗时、工作目录和日志。STA、MSG、DAT 等输出可用于定位计算警告和失败。界面读取周期内，拖选日志或保留文字选区会暂缓显示新日志，并提示存在待显示内容。取消选区后更新到最新内容。

切换作业会切换日志来源。需要连续观察时先取消旧选区。作业文件暂时无更新时，应结合锁文件、求解进程和日志判断状态，界面可能短暂处于完成确认阶段。

## 计算资源和服务器

本机区显示 CPU、内存和当前作业情况。添加服务器时填写地址、SSH 端口、用户名和相应认证方式。首次连接或主机指纹改变时，核对指纹并确认后继续。连接后刷新资源，使用远端文件浏览器选择目录，并进行上传或下载。

远程作业的文件路径、Abaqus 命令和工作目录需与服务器一致。连接失败时检查地址、认证与服务器日志。断开连接后重新连接，再刷新任务状态。上传中断、权限不足和远端命令失败会显示在对应操作日志中。真实 SSH 服务器的完整验收状态见 [验收记录](../06-testing/VALIDATION.md)。

## 重启动链

在正式队列中准备原始和后续重启动作业，然后打开「重启动链」。选择节点，点击「编辑依赖」设置 oldjob 关系，使用「校验全部」检查循环、缺失父节点与路径。可在队列中定位当前节点，核对执行顺序。

「生成此节点完整结果」会转入结果合并计划。计算依赖描述计算的先后关系，完整结果计划描述为目标节点汇总哪些 ODB。分支工况应沿目标节点的祖先路径生成计划，核对后再执行。

## ODB 合并

手工合并时选择原始 ODB 和重启动 ODB，填写目标路径、历史输出及压缩选项。选定命名冲突策略，点击「检查合并计划」。确认来源、目标和是否覆盖后执行合并。

执行期间查看进度。需要停止时使用「停止」并等待操作进入终止状态。成功后可点击「打开结果」或「打开所在目录」。发生错误时保留操作日志，并检查源文件可读性、Abaqus 版本、目标目录权限和剩余空间。

合并完成前会逐步校验帧、场数据及历史输出，较大 ODB 需要额外读取时间。关闭“历史输出”会移除结果中全部历史数据，包括原始分析步的历史数据。来源中无结果帧的分析步会保留并提示；合并成功不等于求解完成。目标目录中的 `*.merge-validation.json` 是本次校验回执。规则、取消时机及恢复边界见 [安全合并说明](../03-features/ODB_MERGE.md)。

多节点计划按唯一祖先路径在后台执行，共享祖先只生成一次。切换页面不影响执行；「读取后台任务」可恢复进度和已完成目标。后台重启后点击「检查并继续批量任务」，校验来源和中间结果后再推进。已提交步骤记录缺失或状态不明时停止接续，不自动重跑。详见 [批量操作与恢复](../03-features/ODB_RESULT_BATCH.md)。

## ODB 后处理

1. 选择 ODB 根目录，点击发现或刷新目录。
2. 选择模型并检查兼容性。需要升级的文件按升级预览确认后处理，完成后重新读取结构。
3. 读取结构与默认参数，逐个核对起止分析步、载荷方向、集合、材料和配筋状态。无纵筋模型选择相应模式。
4. 需要比较的模型填写同一个对比组名并应用分组。保持需要运行的成员处于选中状态。
5. 在「图例范围」选择变量，可使用自动组范围或填写手动上下限。手动最大值须大于最小值。
6. 在「输出与计算设置」填写图像尺寸、背景、纵筋方法、容差和 GIF 播放方式。
7. 点击运行后处理，观察分阶段进度。完成后从结果目录或「结果浏览」查看输出。

像素模式默认输出 1500 × 1000。GIF「统一帧率」可填 1–60 的整数，新工作区默认 25 帧/秒。「统一时长」填写每轮秒数，初始值为 4。已有工作区恢复其保存值。详情、数值约定与异常处理见 [后处理说明](../03-features/POSTPROCESSING.md)。

需要提取某个集合或实例的内力时，打开对象结构浏览入口，按实际单元类型选择提取方法。桁架与钢筋可计算轴力，实体集合使用截面力与弯矩方法。检查结果中对应的实例、单元或截面标识。源文件变化、缺失输出和取消会产生明确失败状态。

## 结果浏览

选择结果根目录，再选择某个时间目录、ODB 或公共数据版本。时间目录首次浏览需点击创建索引。筛选区域可按常用、数据、曲线图、云图、动画、说明与日志等分类，并可搜索文件、用途与描述。列表每页最多 500 条，通过上一页、下一页浏览。

选中文件后，右侧显示预览。CSV 保留原始字符串，Excel 显示首工作表。宽表可切换列组，复制操作包含当前预览行的所有列。超过预览行数时会提示截断，完整内容可通过「打开文件」查看。

「打开所在文件夹」定位原文件。「更多」包含复制路径、导出所选和移到回收站。导出遇到重名自动生成新名称。

清理结果时按 Ctrl 多选文件，选择「更多 → 移到回收站」，核对确认窗口中的文件。系统会继续处理回收站交互。公共数值文件可能被多个对比组引用，清理后这些组的相应内容也会受影响。部分文件失败或取消时，页面显示已完成数量和剩余数量，已清理部分仍刷新索引。在系统回收站还原文件后，重新创建索引。此入口处理 CSV、Excel、图片、动画、文本及日志导出文件。

## 关闭、恢复与故障处理

关闭前查看各页面仍在执行的操作。使用应用的关闭按钮并等待处理完成。结果文件清理期间关闭会等待清理及索引刷新。后台有活动任务时，控制面按任务状态决定继续保留或拒绝安全关闭，界面会显示处理结果。

后处理参数按 ODB 根目录保存。重新发现原根目录后恢复分组、选中状态及输出设置。后台仍存活时可以重连活动操作。单步 ODB 合并还支持后台重启后的历史记录恢复；打开合并页会显示最新任务，未确认完成的任务显示“中断待核对”，不会自动重跑。根据提示核对原进程、目标目录与校验回执后再决定重试。完整结果批量计划现由后台持久保存，重启后需显式检查并继续；真实多阶段模型、原生交互及其他任务的跨后台续接仍在整体验收范围内，详见 [合并恢复说明](../03-features/ODB_MERGE.md)。

| 现象 | 检查和处理 |
|---|---|
| 结果列表为空 | 确认选择了时间目录或 ODB，清除筛选后创建索引 |
| 索引无效或缺失 | 在对应时间目录重新创建索引，保留错误文本 |
| 部分变量缺图 | 检查该变量在所选分析步中是否存在，以及分组范围扫描是否完整 |
| GIF 播放太慢 | 切换统一帧率并增加帧率，或切换统一时长并减小秒数 |
| 数字选项含义不清 | 将鼠标移至选项旁问号查看单位、作用和默认值 |
| 日志显示暂时不更新 | 取消文字选区，让待显示的新日志更新 |
| 文件清理失败 | 检查占用、权限、系统回收站提示，按已完成数量处理剩余文件 |
| 界面启动失败或退出 | 记录候选版本、发生时间和 Windows 应用程序事件，参考开发说明 |

## 交接与问题反馈

交接包应包含源码版本、功能状态、执行过的检查及其输出、复现步骤和准确的下一步。软件生成的模型结果、账户认证信息和本地运行配置分别保存在其工作目录及用户数据目录。

维护者从 [文档入口](../INDEX.md) 进入 [功能索引](../03-features/FUNCTION_INDEX.md)，按功能编号定位源码、测试和任务记录。发现问题时提供页面、操作顺序、期望结果、实际结果及错误文本；涉及 ODB 时注明 Abaqus 版本、分析步、集合和输出字段。
