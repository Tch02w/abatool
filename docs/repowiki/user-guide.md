# Abaqus Tools 使用手册

更新于 2026-11-25，适用于当前 WinUI 3 源码。安装包所含功能按其源码版本核对。[发布说明](../05-development/RELEASE.md) · [当前状态](../08-handoff/CURRENT_STATUS.md)

## 启动和环境

当前提供源码启动方式、Windows x64 自包含目录及安装候选流程。安装/升级/卸载步骤见[安装说明](../05-development/INSTALLATION.md)，实际产物状态以[当前状态](../08-handoff/CURRENT_STATUS.md)为准。源码方式需要 .NET 10 SDK、Python 3.14 和项目虚拟环境；目录候选携带控制面与界面运行库，须完整保留目录。ODB 读取、出图和合并仍需本机 Abaqus。安装依赖、构建和启动命令见 [README](../../README.md)，目录包限制见 [发布说明](../05-development/RELEASE.md)。

首次打开后，查看底部的 Abaqus 探测和控制面状态。若提示控制面不可用，安装版/完整目录版检查程序目录中的 `control-plane/AbaqusTools.ControlPlane.exe` 是否齐全；源码版检查项目根目录的 `.venv/Scripts/python.exe`。源码模式自定义解释器使用 `ABAQUS_TOOLS_PYTHON` 环境变量，自定义项目根目录使用 `ABAQUS_TOOLS_ROOT`。Abaqus 命令可填写安装目录下的 `abaqus.bat` 完整路径。启动失败的定位步骤见 [开发与发布](development.md)。

顶部导航固定包含新建作业、作业队列、作业概览、计算资源、重启动链、ODB 合并、ODB 后处理、结果浏览。左侧浏览器随页面显示对应文件或对象。可步进的数字输入右侧下箭头减小、上箭头增加，数值居中；SSH端口直接输入，不设增减按钮。将鼠标移到参数旁的问号查看说明，移入提示区后可继续阅读，离开后自动关闭。

左侧浏览器右上角的折线按钮（Ctrl+B）可收起或恢复侧栏；收起后保留小型展开入口，当前填写和后台任务继续保留，正常关闭会记住侧栏状态。浏览树采用较小的逐级缩进。结果浏览中的模型节点是存放提取结果的文件夹，副标题为“模型结果目录”，里面的CSV等才是结果文件；原始ODB在工作目录或后处理页按文件显示。安装候选包含哪些更新，以[当前状态](../08-handoff/CURRENT_STATUS.md)为准。

队列会自动更新运行状态、耗时和内存；相同数据不重建列表，候选/正式行选择与勾选保持。后台自动观测不让“扫描”按钮闪烁。作业名按[Abaqus 2025规则](../03-features/JOB_NAMING.md)校验，允许`GJA-8+2`这类加号名称。

## 关闭窗口

后处理页现在会定期保留输出设置和未确认弹窗的填写。重开、发现原目录后如出现恢复提示，先查看，再选择恢复或保留副本后忽略；ODB或正式配置变化时不能直接恢复。恢复后须重新读取结构，再打开原参数/图例/分组弹窗确认填写；它们不会自动提交。完整操作和限制见[后处理恢复说明](../03-features/POSTPROCESSING.md)。已进入7c874d3完整候选，原生交互仍待验证。

当前完整候选包含每两秒的输入草稿检查点：内容变化才写盘，失败时顶部提示，成功后提示消失。关机或注销时另作一次限时保存，取消注销不会退出工作台。它覆盖登记的页面输入和窗口状态，后处理详细工作区、结果图和未确认弹窗仍按各自保存规则处理；不保证突然断电时保留最后编辑，也不保证本机计算跨系统重启继续。原生流程待验收，实际候选见[当前状态](../08-handoff/CURRENT_STATUS.md)。

有活动任务时，选「后台继续」可以关闭窗口，下次打开仍可查看原任务和日志。选「停止任务并关闭」会请求停止并等待清理。选「取消关闭」会返回工作台。没有活动任务时可直接退出。已发出的停止请求会继续生效。

关闭前自动保存已登记页面的输入、最近页面及窗口大小，并等待正在提交、保存或清理的操作。保存失败会留在界面并显示原因。草稿保存在 `%LOCALAPPDATA%/AbaqusTools/workbench-session.json`，不会保存密码。重新打开后从后台读取真实任务状态；计算资源页可接回仍在传输的文件进度。「后台继续」要求原后台仍在运行，不等于所有任务都能在电脑重启后恢复。详细保存范围见 [界面与退出说明](../03-features/UI_INTERACTION.md)。

## 新建作业

重开时会恢复已保存的 CPU 填写值，再根据取得的本机 CPU 上限检查；暂时无法取得上限时保留填写并提示，提交/预览仍会校验。此次原生验收已确认名称和 CPU=4 关闭后恢复，其他字段和有任务时退出仍按验收清单分别检查。

普通顶部导航会保留当前填写。要开始另一份作业，选择「文件 → 新建作业」。有已填内容时，点「保留当前填写」可继续编辑。点「清空并新建」会清除名称、INP、重启动依赖及子程序路径，回到本机执行，保留 CPU 和内存等常用设置。保存失败时输入仍可编辑，排除保存问题后可再次新建。

2026-11-24 在真实窗口核对了上述两种选择、切换页面和保存失败后的重试。另用本机作业核对 CPU 增减、内存和命令预览，点击「提交作业（加入队列）」后，队列中保存了一条 4 核、63% 内存的待运行作业。[原生验收记录](../08-handoff/ACTIVE_TASKS/TASK-004-ui-interaction.md)

1. 点击「选择 INP…」并填写作业名称。需要用户子程序时点击「选择 FOR…」。重启动作业需指定旧作业文件。
2. 选择本机计算、上传至已连接服务器或使用服务器现有文件。远端模式先在「计算资源」完成连接。
3. 填写 CPU、内存及其单位，并按模型需要选择作业选项。CPU=0 采用 Abaqus 默认设置。正式队列入队时需要明确可调度的 Core 数。Abaqus ≤2021 的本机上限按逻辑线程计算，较新版本按物理核心计算。GPU 和精度在下方“GPU 与精度（可选）”中设置，默认沿用环境配置。勾选“指定”后 GPU=0 明确关闭；计算精度只对应 Explicit，ODB 场输出精度另选。先点命令预览核对。正式队列“编辑”可修改同组选项；说明见 [GPU 与精度](../03-features/EXECUTION_OPTIONS.md)。
4. 使用 SSD 计算时启用对应选项，填写计算目录和归档目录。核对预览中的实际工作目录、命令和 oldjob 参数。
5. 执行页面上的校验及提交操作。校验报错时先修正对应字段，随后重新预览。到「作业队列」核对条目，去「作业概览」查看运行过程。

本地和远程提交使用各自的路径格式。服务器现有文件模式中的路径以服务器文件系统为准。相同结果文件的处理方式应在运行前确定。

本机运行先检查路径、当前/前置作业 LCK、子程序和同名结果策略，再准备文件。拒绝时在作业概览核对具体原因；失败记录重启后保留，不会自动重试。不要仅因看到 LCK 就删除它，先核对对应作业是否仍运行。准备中取消不会再启动新进程；已准备的较早文件可能保留。数据检查支持含空格的 INP 文件名。详细复制保护及尚未完成的归档边界见 [工作目录准备](../03-features/LOCAL_WORKSPACE.md)。

勾选“结束提醒”后，本机或远端作业确认完成、失败或取消时，窗口顶部显示集中提醒。点“查看提醒”可打开对应执行、复制原目录，或标为已读；每页最多 50 条，不会清除尚未显示的提醒。未读记录在重开界面/后台后保留，旧执行不会因为轮询而重复提醒。后台继续运行但界面已关闭时，下次打开再显示未读，不发送系统通知中心推送。保存失败时保留后台并按提示检查磁盘。详见 [作业结束提醒](../03-features/JOB_NOTIFICATIONS.md)。

独立恢复归档会显示「本机归档」提醒。归档结果已保存后即使后台意外退出、尚未来得及提醒，新后台仍可补发；清除已完成队列不会清除这条提醒，已读后不重复出现。「查看作业」只定位原求解执行；队列已清除时保留提醒和结果目录，不跳到同名的新执行。

## 作业队列

选中候选作业所在行，点「编辑候选」可以补填 Restart 前置 ODB、Core、优先级和内存。正式作业使用「编辑」打开同一张表单。Core 和优先级支持直接输入，也可以点右侧的下、上折线逐步减小或增加。保存遇到校验问题时，窗口会保留已填写的值，便于修改后重试。

单条作业的计算根目录和归档根目录位于「计算与归档目录」。同时调整多个候选时，先勾选作业，再点「批量设置目录…」。两个目录可分别选择保留、设置或清除。归档后是否清理独立作业目录也可以单独选择，新增目录时默认保留作业副本。[目录填写说明](../03-features/LOCAL_SCHEDULING.md)

“作业”菜单与本页按钮共享可用状态；读取不到状态或正在处理时暂时禁用。选择运行中的作业后可用“终止所选运行中作业…”，确认框列出名称和数量；“停止后续调度”只停止安排新任务，已运行作业继续。服务器菜单“刷新远端资源”及“断开远端连接”只对已连接服务器可用；后台正在刷新时本机刷新和配置编辑仍可用。连接变化提示“原服务器不匹配”时先核对资源页，不重复点击旧操作。

归档目录中先生成完整、校验后的副本，未勾选清理时原文件保留。作业概览状态卡另显示归档结果，队列备注和结束提醒保留失败原因；「计算完成」不等于「归档完成」。失败、取消或后台中断后，若有有效记录，可在 **作业概览 → 选择作业 → 恢复归档** 继续核对和复制/清理，不会重新计算。处理中可「取消归档」，已有文件保留。提示「归档记录异常」时需先核对目录与原配置，不要通过重新排队来重试；详见 [本机归档说明](../03-features/LOCAL_ARCHIVE.md)。

候选区和正式队列的每行下方、相邻两列之间均有细线。序号与表头居中，作业名和 INP 路径从各自的左边界开始。下图第三行的作业名较长，末尾显示省略号。把鼠标移到名称上可以读全名。窗口较窄时，可在表格底部横向滚动到右侧的列，表头会一起移动。

![候选区示例，长作业名在名称列内省略，名称与 INP 路径之间有细线](images/job-queue-light.png)

候选区的勾选决定哪些作业会在「确认入队」时加入队列。正式队列的勾选用于选择要操作的作业。[查看深色主题效果](images/job-queue-dark.png)

候选区用于收集准备计算的 INP，正式队列用于调度。选择工作目录后可加入当前 INP、添加其他 INP 或扫描文件夹。扫描选项控制是否包括子文件夹、是否跳过 Restart 文件和已有结果的作业。勾选候选并点击「确认入队」，检查正式队列中的 Core、内存、优先级和重启动依赖。

设置「并行上限」后点击「开始队列」。优先级高的先分配，相同优先级按队列顺序；CPU、绝对内存、依赖或同目录冲突不足时显示等待原因。暂停调度用于暂停后续派发，恢复调度继续派发。终止操作作用于当前后台启动的运行作业，应先核对当前选择。上下移动影响相同优先级的顺序，重新排队仍需通过资源与依赖检查。

![正式队列工具栏中并排的同名结果策略和并行上限](images/job-queue-toolbar.png)

后台重启后，原活动记录先显示「状态未知」，自动扫描原工作目录核对，不会重复提交或自动继续派发。核对前不能删除、清理或重新排队。若扫描后仍无完成证据，显示「待确认」，确认原作业已结束后再重新排队。保存失败会暂停新派发并显示原因，已有作业继续监控；完成结果保存会重试，不重新计算。`90%` 仍是求解器上限，不能保证并发总内存充足。完整资源与恢复边界见 [本机调度说明](../03-features/LOCAL_SCHEDULING.md)。

队列及作业概览中的「内存」显示当前进程工作集合计。鼠标停在数值上可查看本次观测峰值、调度估计及来源；历史估计会随同模型/执行参数保存。显示「采集中」「暂不可读」「待更新」时，不代表占用为零；已结束作业保留峰值。调度以当前可用内存的 85% 为预算，并参考绝对配置及峰值安全余量。没有本模型历史时，其他作业的估计会明确标为参考；冷启动完全未知时仍按 CPU/并行上限准入。估计无法保证避免全部内存不足，详情见 [内存说明](../03-features/MEMORY_MONITORING.md)。

外部启动的作业可通过正式队列上方「工作目录 → 扫描」纳管。扫描后核对名称、路径与状态。结果冲突可选择备份旧结果等策略，具体动作以执行前预览为准。

外部扫描显示「扫描中…」时，状态区继续读取最近保存的队列，不必重复点击扫描。扫描期间修改的条目受到保护，完成提示如显示跳过了变化记录，可稍后再次刷新；扫描失败不会把部分发现结果写回队列。此处扫描与候选区扫描 INP 是两个操作。

「停止调度」只停止启动后续作业，当前作业继续运行；「终止运行中」才结束所选自有作业。CPU和内存同时不足时，等待原因可能先显示CPU限制，资源释放后再显示内存限制。开启结束提醒时，数据检查失败也会通知；其“失败”状态不会视为求解成功。

## 作业概览和日志

查看历史远端作业时，点「目录」浏览该作业原服务器的工作目录。STA、MSG、DAT 按钮下载对应的作业输出。若提示连接已改变，在「计算资源」连回提示中的主机和端口后重试。浏览目录时，用「进入」查看子目录，用「关闭」返回概览。

选中一个作业后查看状态、进度、耗时、工作目录和日志。STA、MSG、DAT 等输出可用于定位计算警告和失败。界面读取周期内，拖选日志或保留文字选区会暂缓显示新日志，并提示存在待显示内容。取消选区后更新到最新内容。

切换作业会切换日志来源。需要连续观察时先取消旧选区。作业文件暂时无更新时，应结合锁文件、求解进程和日志判断状态，界面可能短暂处于完成确认阶段。

## 计算资源和服务器

本机区显示 CPU、内存和当前作业情况。添加服务器时填写地址、SSH 端口、用户名和相应认证方式。首次连接或主机指纹改变时，核对指纹并确认后继续。连接后刷新资源，使用远端文件浏览器选择目录，并进行上传或下载。

传输先写临时文件，完整保存后才显示成功。未允许覆盖时保留同名目标；取消发生在保存完成后，已完成文件仍显示成功。独立传输记录不承诺重启后台后恢复。Windows下载同步和覆盖保护的修复状态、错误处理及实际验收见[远端传输说明](../03-features/REMOTE_TRANSFERS.md)。

切换页面不会取消传输；返回计算资源页会继续读取原任务。出现“传输状态暂未确认”时，应用会自动重查，也可点击刷新，请勿重复上传/下载。只有后台明确返回结果才显示完成或失败。若提示原记录不可用，核对服务器和目标文件，不能仅凭进度判断是否保存成功。

服务器响应较慢时，资源页先显示最近一次完整状态，并提示正在更新。如果出现“资源值为上次读取”，CPU/内存尚未重新采样；等待更新结束即可，不需要反复点击刷新。切换服务器期间不会沿用前一台机器的资源数值。连接失败或需确认指纹时，页面会显示对应状态。

远程作业的文件路径、Abaqus 命令和工作目录需与服务器一致。连接失败时检查地址、认证与服务器日志，在「计算资源」连接原服务器；有活动作业时不能切换到另一服务器或主动断开，恢复连接仍允许。上传中断、权限不足和远端命令失败会显示在对应操作日志中。真实 SSH 服务器的完整验收状态见 [验收记录](../06-testing/VALIDATION.md)。

远端显示“已收到完成输出，正在确认进程和文件已结束”时，请等待稳定确认；这时仍属于活动作业。数据检查必须有明确成功输出，不能只凭进程消失算成功。取消也需确认退出后才结束；日志轮询只追加新增内容。若显示“未发现成功标记”，应检查远端原始日志。

SSH 中断或后台重启后，原任务显示“等待重连核对”，连接原服务器即可继续观察，不要重新提交来找回任务。显示“提交状态待核对”表示启动回执不足，需检查原服务器目录与进程；系统不会擅自再启动。离线时可请求取消，连接恢复并核对任务后执行。记录保存警告出现时保留后台、检查磁盘；未核对状态时暂停/恢复禁用。旧版本没有保存记录的任务不能自动恢复，详见 [远端作业说明](../03-features/REMOTE_JOBS.md)。

## 重启动链

在正式队列中准备原始和后续重启动作业，然后打开「重启动链」。选择节点，点击「编辑依赖」设置 oldjob 关系，使用「校验全部」检查循环、缺失父节点与路径。可在队列中定位当前节点，核对执行顺序。

「生成此节点完整结果」会转入结果合并计划。计算依赖描述计算的先后关系，完整结果计划描述为目标节点汇总哪些 ODB。分支工况应沿目标节点的祖先路径生成计划，核对后再执行。

## ODB 合并

当前候选会独立保存未提交的结果图编辑。重开后若出现「发现未保存的结果图」，基线未变时点「恢复编辑」，核对后再点「保存」。若正式图已变化，先「查看草稿」复制需要保留的内容，或「保留副本并忽略」使用正式版本；不会自动覆盖新图。草稿是JSON元数据，不复制ODB，也不会自动启动合并。此恢复入口已包含于当前完整包，原生操作仍按[原生验收步骤](../06-testing/NATIVE_ACCEPTANCE.md)检查，发布来源见[当前状态](../08-handoff/CURRENT_STATUS.md)。

手工合并时选择原始 ODB 和重启动 ODB，填写目标路径、历史输出及压缩选项。选定命名冲突策略，点击「检查合并计划」。确认来源、目标和是否覆盖后执行合并。

手工合并请求得到后台确认后，「停止」会启用。点击一次并等待页面显示已停止。成功完成的合并可用「打开结果」或「打开所在目录」查看。发生错误时保留操作日志，可检查源文件可读性、Abaqus 版本、目标目录权限和剩余空间。

合并完成前会逐步校验帧、场数据及历史输出，较大 ODB 需要额外读取时间。关闭“历史输出”会移除结果中全部历史数据，包括原始分析步的历史数据。来源中无结果帧的分析步会保留并提示；合并成功不等于求解完成。目标目录中的 `*.merge-validation.json` 是本次校验回执。规则、取消时机及恢复边界见 [安全合并说明](../03-features/ODB_MERGE.md)。

多节点计划按唯一祖先路径在后台执行，共享祖先只生成一次。切换页面不影响执行；「读取后台任务」可恢复进度和已完成目标。后台重启后点击「检查并继续批量任务」，校验来源和中间结果后再推进。已提交步骤记录缺失或状态不明时停止接续，不自动重跑。详见 [批量操作与恢复](../03-features/ODB_RESULT_BATCH.md)。

## ODB 后处理

要优先提取某个对比组，打开「选择与对比组 → 对比组执行顺序」，上移该组并保存。点「查看完整执行顺序」可核对本次实际派发的组和独立模型，追加任务时会跳过正在执行或等待的组。[分组队列与示例](postprocessor.md)

从作业打开结果：在作业概览选择一个作业，或在正式队列中只选中一个作业，再点“后处理 → 当前作业送入后处理”。它核对该次运行并定位已发布归档或实际计算目录中的ODB；新建页则按当前本地输入查找。没有结果、正在运行、归档未结束或选择已变会说明原因。远端作业先在计算资源文件浏览器下载到你选择的本地目录，再到后处理页读取。此入口不复制或移动文件，也不自动提取。若目标工作区出现旧草稿提示，先处理恢复；直接打开页面仍用“打开 ODB 后处理”或Ctrl+7。详细来源和错误规则见[后处理说明](../03-features/POSTPROCESSING.md)。此项已进入22e47f6完整候选，原生交互仍待验。

1. 选择 ODB 根目录，点击发现或刷新目录。
2. 选择模型并检查兼容性。需要升级的文件按升级预览确认后处理，完成后重新读取结构。
3. 读取结构与默认参数，核对起止分析步、载荷方向、集合、材料和配筋状态。选中多个模型可点「对照提取参数…」逐格编辑，或只把勾选的参数应用到其他模型。无纵筋模型选择相应模式。[多模型编辑与分组](postprocessor.md)
4. 需要比较的模型填写同一个对比组名并应用分组。也可以先点「新建对比组…」粘贴名称，再逐组添加模型。保持需要运行的成员处于选中状态。
5. 在「图例范围」选择变量，可使用自动组范围或填写手动上下限。手动最大值须大于最小值。
6. 在「输出与计算设置」填写图像尺寸、背景、纵筋方法、容差和 GIF 播放方式。
7. 从「运行范围」选择按所选模型的全部分组运行、只运行某个组，或独立运行一个模型。看清成员数后点「运行后处理」。运行中可以追加、编辑等待组或取消当前组，再从「打开结果浏览」查看已发布的结果。[按组出图与队列操作](postprocessor.md)

像素模式默认输出 1500 × 1000。GIF「统一帧率」可填 1–60 的整数，新工作区默认 25 帧/秒。「统一时长」填写每轮秒数，初始值为 4。已有工作区恢复其保存值。详情、数值约定与异常处理见 [后处理说明](../03-features/POSTPROCESSING.md)。

需要提取某个集合或实例的内力时，打开对象结构浏览入口，按实际单元类型选择提取方法。桁架与钢筋可计算轴力，实体集合使用截面力与弯矩方法。检查结果中对应的实例、单元或截面标识。源文件变化、缺失输出和取消会产生明确失败状态。

## 结果浏览

刚完成提取时，可在「ODB 后处理」点「打开结果浏览」并选择已发布的位置。手工选择根目录时，进入相应 ODB 所在目录旁的 `AbaqusODBPostProcessor_Results`。例如模型为 `D:\试验\模型甲\算例.odb`，结果根目录就是 `D:\试验\模型甲\AbaqusODBPostProcessor_Results`。一次提取涉及不同子目录的模型时，可以分别打开它们的已发布结果。

输入新的根目录后，点击「读取目录」或按Enter才切换结果。尚未读取时，路径框下方会提示当前显示及操作目录；筛选、分页、索引、导出和清理仍作用于当前显示内容。侧栏刷新和索引完成不会把未提交路径直接应用。

选择结果根目录，再选择某个时间目录、ODB 或公共数据版本。时间目录首次浏览需点击创建索引。筛选区域可按常用、数据、曲线图、云图、动画、说明与日志等分类，并可搜索文件、用途与描述。列表每页最多 500 条，通过上一页、下一页浏览。

选中文件后，右侧显示预览。CSV 保留原始字符串，Excel 显示首工作表。宽表可切换列组，复制操作包含当前预览行的所有列。超过预览行数时会提示截断，完整内容可通过「打开文件」查看。

「打开所在文件夹」定位原文件。「更多」包含复制路径、导出所选和移到回收站。导出遇到重名自动生成新名称。

点「更多 → 导出所选」并选择目标目录，底部会显示进度。点「取消导出」会保留已完成项。展开「导出记录」核对已完成和剩余的路径。记录保留在当前页面会话中，导出期间关闭窗口会先等待，超时后可以返回查看进度或取消导出。

清理结果时按 Ctrl 多选文件，选择「更多 → 移到回收站」，核对确认窗口中的文件。系统会继续处理回收站交互。公共数值文件可能被多个对比组引用，清理后这些组的相应内容也会受影响。部分文件失败或取消时，页面显示已完成数量和剩余数量，已清理部分仍刷新索引。在系统回收站还原文件后，重新创建索引。此入口处理 CSV、Excel、图片、动画、文本及日志导出文件。

## 关闭、恢复与故障处理

使用窗口关闭按钮或「文件 → 退出」，根据上文选择后台继续、停止并关闭或取消。结果文件清理期间会先等待清理及索引刷新。清理超时、图保存冲突或草稿文件损坏时保留窗口；根据显示的原因处理后再试。无法连接后台时，可显式选择保留后台并关闭窗口；不会根据未知状态结束进程。

后处理参数按 ODB 根目录保存。重新发现原根目录后恢复分组、选中状态及输出设置。后台仍存活时可以重连活动操作。单步 ODB 合并还支持后台重启后的历史记录恢复；打开合并页会显示最新任务，未确认完成的任务显示“中断待核对”，不会自动重跑。根据提示核对原进程、目标目录与校验回执后再决定重试。完整结果批量计划现由后台持久保存，重启后需显式检查并继续；真实多阶段模型、原生交互及其他任务的跨后台续接仍在整体验收范围内，详见 [合并恢复说明](../03-features/ODB_MERGE.md)。

| 现象 | 检查和处理 |
|---|---|
| 结果列表为空 | 确认选择了时间目录或 ODB，清除筛选后创建索引 |
| 索引无效或缺失 | 在对应时间目录重新创建索引，保留错误文本 |
| 部分变量缺图 | 检查该变量在所选分析步中是否存在，以及分组范围扫描是否完整 |
| GIF 播放太慢 | 切换统一帧率并增加帧率，或切换统一时长并减小秒数 |
| 数字选项含义不清 | 将鼠标移至选项旁问号查看单位、作用和默认值 |
| 日志显示暂时不更新 | 取消文字选区，让待显示的新日志更新 |
| 文件清理失败 | 检查占用、权限、系统回收站提示，按已完成数量处理剩余文件 |
| 界面启动失败或退出 | 记录候选版本、发生时间和 Windows 应用程序事件，参考开发说明 |
