# ADR 0005：WinUI 目录包携带独立控制面

状态：已采用；目标机器和正式发布验收未完成。

## 问题

开发构建必须向上找到源码根目录和 `.venv`。单独复制 WinUI 输出无法启动控制面，且 Windows App SDK 自包含不意味着 .NET 自包含。

## 决策

使用 WinUI + .NET 自包含目录和 PyInstaller one-folder 控制面，保留现有 HTTP/DTO 与 Abaqus worker 边界。先选择同级 `control-plane`，再对开发构建查找源码。显式根目录优先；外部 Python 只用于源码模式。损坏的目录包不得静默回退开发环境。

打包既有 Python 依赖和 worker 资源，排除 Qt。控制面保持独立进程、现有鉴权、进程归属及安全关闭；不把 Abaqus 解释器或许可证装入包。应用配置保持用户目录路径。每次生成独立产物并附文件摘要、源提交和 dirty 标记。

## 影响与验收

包体积增加，但目标机器无需项目 `.venv` 或 .NET SDK。资源以模块 `__file__` 的相对位置读取；不把用户模型/配置复制为资源。正式迁移仍保留 PySide6 源码对照入口。

必须独立验证包内依赖、主机冷启动/关闭、迁移后的路径、原生窗口和干净机器。目录候选不等于已签名安装包。步骤及证据入口见 [发布构建](../../05-development/RELEASE.md)。
