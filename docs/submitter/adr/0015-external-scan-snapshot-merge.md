# ADR 0015：外部扫描离锁计算与条件合并

- 日期：2026-11-18
- 状态：已实现；原生交互和大规模工程负载待验收

## 问题

手动扫描和周期扫描曾在队列事务锁内枚举进程、读取目录并诊断日志。慢扫描会阻塞状态读取及队列修改。仅把进程查询移出锁仍会被合并阶段的日志诊断阻塞。

## 决定

用单独的非阻塞扫描锁限制同一后台一轮扫描。短队列事务读取分离副本及完整条目基线，锁外执行扫描和诊断；生产扫描器对多目录共用进程枚举，保留扩展扫描器原有双参数接口。回写时重新加载最新队列，逐条比较完整基线，只替换未变化的旧条目；新增条目同时检查身份和目录/作业冲突键。本机活动执行与归档状态由原执行器管理。关闭标记与最终合并在同一队列锁内检查。

读取公开 `externalScanActive` 和最近保存的队列；忙时拒绝重复手动扫描。失败不保存分离副本。新增/更新统计按实际合并结果计算，过期结果明确计数，不冒充本轮更新成功。

## 代价与验证

完整条目匹配较保守：即使只改勾选也会推迟该行的扫描更新，下一轮重新采集。仍有队列文件读写的短事务，不能据此保证任何磁盘/网络环境下恒定延迟；没有新增扫描取消机制。

用事件屏障证明慢扫描和慢诊断期间读取已经返回，覆盖重复、关闭、失败后重试、并发修改与新条目冲突。正式 C# 客户端配合自有非求解进程核对实际发现、扫描期间读取和进程结束。定位与证据见 [功能说明](../../03-features/LOCAL_SCHEDULING.md) 和 [TASK-002](../../08-handoff/ACTIVE_TASKS/TASK-002-migration.md)。
