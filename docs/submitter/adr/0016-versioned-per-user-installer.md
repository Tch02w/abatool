# ADR 0016：按用户安装与独立版本目录

状态：已采用；隔离生命周期通过，正式目标机、签名及原生向导待验收。

## 问题与决策

手工复制目录可能漏文件、覆盖活动后台或混合依赖。保留 ADR 0005 的完整 WinUI/Qt-free 负载，使用 Inno Setup 按用户安装；安装目录与已有用户数据分离。

固定安装标识、精确文件清单和归属标记管理安装。负载按源码及清单摘要放入独立版本目录，新文件校验后更新入口；升级不删除旧版本，不增加递归目录删除规则。安装/卸载检查目录归属、目录链接及活动工作台/控制面，无法检查时停止，不自动关闭或强杀用户任务。

正式构建要求干净源码，分别记录安装器与负载版本。测试构建使用独立标识，只在GPTWork新目录进行，核对测试注册和快捷方式最终移除。安装器不启动应用/求解，不迁移数据格式，不声明自动降级。

## 影响与限制

旧版本占用额外磁盘，但清理不与更新耦合。活动进程查询依赖 Windows 管理服务；普通失败使用安装引擎回滚，不承诺断电原子性。签名、正式标识在目标机的安装及原生交互仍需验收。

命令及证据见[安装说明](../../05-development/INSTALLATION.md)和[TASK-002](../../08-handoff/ACTIVE_TASKS/TASK-002-migration.md)。
