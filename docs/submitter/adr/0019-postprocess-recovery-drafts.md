# ADR 0019：后处理工作区与未确认弹窗的独立草稿

状态：已实现，原生交互待验收。日期：2026-11-18。关联 F001/F022。

## 问题与选择

正式工作区只在选择、分组、页面退出等时机保存，不能代表弹窗中尚未确认的输入。使用现有定期检查点，每个根目录保存独立恢复文件，不在检查点或系统结束回调中执行后台提交、ODB 读取或正式配置保存。比仅保存已确认配置多覆盖半填数字、手动帧表达式、图例输入、重命名和组内顺序；恢复仍须由用户选择。

`OdbPostprocessingPage.Drafts.cs` 同步捕获原始字符串、可编辑工作区、正式配置指纹及最近一次目录发现返回的路径/大小/修改时间。`DialogDrafts.cs` 登记四类弹窗，保存各自配置/可选集合/源文件身份基线，取消不提交，保存后移除对应草稿；原件尚待处理时不覆盖。切换目录前等待当前草稿写入。恢复期间抑制正式自动保存；弹窗保留/恢复过程中阻止关闭，避免取消后异步套用。

## 文件与边界

- `%LOCALAPPDATA%/AbaqusTools/postprocess-recovery/<根目录SHA256>.json`，schema 1。只存 JSON 配置，不复制、移动或生成 ODB。测试文件全部放 G: 项目 GPTWork。
- 最多 8 MiB、10000 个 ODB 身份、128 个弹窗；每组原始输入最多256字段，每字段65536字符。超限或损坏保留原件并提示，不用默认值覆盖。
- `RecoveryDraftFile<T>` 与结果图共用：UI线程先验证/序列化不可变快照，后台依序写临时文件、flush、替换；相同内容不重复写。保留副本先逐字节复制并flush，成功后才允许清活动检查点；失败不清原件。
- 根目录、正式配置规范化内容、发现列表的源文件身份必须一致才能恢复。字典键顺序不构成冲突，成员数组顺序构成冲突。身份是元数据，不是文件完整摘要或实时stat；恢复后结构有效性清空，须重新读取结构并沿用执行前的源检查。
- 冲突可以查看/复制或保留 JSON 后忽略，不自动合并。弹窗恢复只填写编辑器；仍须其保存/重命名/排序按钮才应用。输入选项变化或恢复异常尝试回滚，保留原件和副本。
- 数字框回填后核对原文或等价有限数值；控件若归一化丢失半填文字则报字段错误、尝试回滚，不静默声称恢复。仅接回运行任务的部分行沿用已有保护，不覆盖完整工作区；需先发现完整目录。

## 验证范围

`tests/winui_postprocess/PostprocessDraftChecks.cs` 使用生产存储/指纹/行准备逻辑验证原文、不可变捕获、身份冲突、结构失效、正式文件不变、损坏/超限/文件占用保护和串行写入。既有结果图回归检查共享存储提取没有改变语义；壳层检查只证明接线，不能代替原生鼠标/键盘/关闭重开和数值控件恢复。准确回执见 [TASK-002](../../08-handoff/ACTIVE_TASKS/TASK-002-migration.md)。
