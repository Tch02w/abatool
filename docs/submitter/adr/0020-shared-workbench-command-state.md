# ADR 0020：菜单与页面共用操作状态

状态：已实现，原生交互待验。日期：2026-11-18。关联F001/F004/F005/F008。

## 选择

由App持有UI线程的WorkbenchCommandState，菜单、页面按钮和执行方法使用同一可用条件。状态来自控制面运行/连接快照，加上当前页面操作、选择、后台远端刷新和关闭/新建锁定；未知或读取失败时不开放对应危险操作。只保存显示状态，不替代后台调度/连接锁、活动任务保护或真实运行事实。

MainWindow每次既有3秒状态周期读取队列运行状态和已发布远端状态；队列页显示时复用它原有1.5秒读取。并发读取合并为各一项；状态观察只发GET，不增加SSH资源命令。操作开始/结束和新快照推进本地版本，迟到的旧观察不能覆盖较新操作。远端后台刷新单独计忙，只阻止重复远端刷新/断开，本机刷新及配置编辑仍可用。

菜单可从其他页面进入：先等目标页首次/再次加载完成，再检查当前页面、可用条件及目标。页面已切走、连接或选择变化时不自动换目标、不补发命令；30秒观察等待超时报告未执行，不自行重启加载。终止操作只包含所选与活动ID的交集，确认中列出名称与数量，取消不发请求。停止调度仍允许已经运行的作业继续。

## 远端身份

原生刷新/断开和后台资源刷新携带操作发起时的非敏感profile。控制面在连接通信锁内用现有server_identity口径核对host/port/username/fingerprint/computeRoot/abaqusCommand/allowedRoots；不匹配返回409 REMOTE_CONNECTION_CHANGED，不调用实际刷新或断开。已有客户端未附profile时保留兼容语义。原生菜单保存开始时的profile，不能在等待页面期间改用同名但不同主机配置。

## 验证

生产状态检查覆盖未知/空闲/运行/停止调度后仍运行、选择交集、错误、忙碌、关闭取消、连接变化和旧读取。正式C#客户端针对本机隔离HTTP验证只读观察不触发SSH操作，并验证错误目标拒绝、正确目标成功；远端使用替身，不能称真实SSH验收。具体回执见[TASK-002](../../08-handoff/ACTIVE_TASKS/TASK-002-migration.md)。原生菜单、页面首次加载、跨页选择与确认仍待用户允许的桌面验收。
